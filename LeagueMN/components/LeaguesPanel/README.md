# LeaguesPanel

'Явагдаж буй лигүүд' — гарчгийн хажууд анивчдаг ногоон `active` цэг.

- Мөр: 48px tile (лигийн өнгө 14% tint + лого эсвэл 2 үсэг), нэр, улирал, 4px progress (лигийн өнгө, `sunken` зам), '12/30 · 8 баг', chevron.
- Лигийн өнгийг `--lc` хувьсагчаар дамжуул (`league-*` токен эсвэл лигийн өөрийн hex).
- Progress нь `role=progressbar` + aria утгатай.
- Хоосон бол 'Одоогоор явагдаж буй лиг алга'; хөлийн холбоос нуугдана.
